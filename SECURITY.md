# Security Policy

Floe Note is experimental software and has not undergone an independent security audit.

## Supported versions

Security fixes target the latest release and current development version. Older versions are not guaranteed updates.

## Reporting a vulnerability

Please use [GitHub Private Vulnerability Reporting](https://github.com/kentakom1213/floenote/security/advisories/new) rather than opening a public issue.

Include a description, reproduction steps, potential impact, and relevant version or environment details. Do not include actual note contents, credentials, or private keys.

## Response and disclosure

Reports are reviewed as availability permits. No response or resolution timeframe is guaranteed. Confirmed vulnerabilities will be addressed and disclosed as appropriate.

For the security model and known limitations, see [Architecture](docs/architecture.md).
